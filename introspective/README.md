# КСИВА

Текстовая новелла на Next.js / React с собственным движком.

## Запуск

Требуется Node.js 20.9 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала. Для статической сборки: `npm run build`. Каталог `out/` можно разместить на статическом хостинге.

## Текст и движок

- `source/novel.txt` — полный исходный текст, включая авторские ремарки.
- `lib/engine.mjs` — разбор сцен, голосов, реплик и границы навигации.
- `app/novel.js` — воспроизведение, печать текста, клавиатура, звук, локальное сохранение.
- `app/globals.css` — оформление под референс и мобильная версия.
- `public/fonts/Hypermarket-Regular.ttf` — предоставленный шрифт.

Начало строки `сцена N` переключает сцену. Реплики `ксива:`, `ксива (другого цвета):`, `ксива (в прошлом):`, `кто-то (в прошлом):`, `голос коммуникатора:` определяют голос и цвет. Остальные абзацы — повествование. Пустые реплики не отображаются. Авторские ремарки сохранены как повествование; иллюстрации персонажей и корабля не предоставлены. Фон — абстрактные пятна по референсу, не изображение корабля. Развилки не добавлены: рукопись линейная и не закончена.

Клик / пробел / Enter / → раскрывает реплику, затем переходит дальше. ← возвращает назад. `sound` включает синтезированный звук переходов; `restart` сбрасывает прохождение после подтверждения; `info` показывает управление. Место чтения хранится только в браузере. Системная настройка уменьшения движения отключает печать по буквам.
